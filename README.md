# Aerial Cloud

A learning cloud-drive web application built with Flask, SQLAlchemy, SQLite, HTML, CSS and JavaScript.

## Current Features

- User registration and login
- Session-based authentication
- Folder creation
- Folder navigation
- Rename folders
- Copy folders
- Move folders
- Delete folders
- File upload
- File download
- Context menus
- Breadcrumb navigation

source venv/bin/activate
